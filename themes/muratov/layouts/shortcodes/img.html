{{- $title := .Get "mouse" | default (.Get "description") -}} {{- $preset := .Get "preset" | default (.Get "size") | default "md" -}} {{- $classes := slice "img-preset" (printf "img-preset-%s" $preset) -}} {{- $width := .Get "width" -}} {{- $height := .Get "height" -}} {{- with .Get "class" -}} {{- $classes = $classes | append . -}} {{- end -}} {{- $src := .Get "src" -}} {{- $srcset := "" -}} {{- $res := .Page.Resources.Get $src -}} {{- if and $res (ne (.Get "original") "true") (in (slice "png" "jpeg" "webp") $res.MediaType.SubType) -}} {{- $display := int ($width | default 800) -}} {{- $w1 := math.Min $display $res.Width | int -}} {{- $w2 := math.Min (mul $display 2) $res.Width | int -}} {{- $one := $res.Resize (printf "%dx webp q80" $w1) -}} {{- $src = $one.RelPermalink -}} {{- if gt $w2 $w1 -}} {{- $two := $res.Resize (printf "%dx webp q80" $w2) -}} {{- $srcset = printf "%s 1x, %s 2x" $one.RelPermalink $two.RelPermalink -}} {{- end -}} {{- if and $width (not $height) -}} {{- $height = div (mul $display $res.Height) $res.Width -}} {{- end -}} {{- end -}} {{- with .Get "caption" }} {{ end -}}
